# D3 + React Practice

A minimal React + D3 project powered by Vite.

## Prerequisites

- **Node.js** (e.g., via `nvm`)

```bash
nvm use 20
```

## Getting Started

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Start the development server:**

   ```bash
   npm run dev
   ```

   The app will start at `http://localhost:5173/`.

   - **Open in VS Code Simple Browser:** Press `Cmd + Shift + P` → **Simple Browser: Show** → enter `http://localhost:5173` (or run **Tasks: Run Task** → **Open in Simple Browser**).

## Available Scripts

- `npm run dev` — Start the Vite development server
- `npm run build` — Build for production into `dist/`
- `npm run preview` — Preview the production build locally
